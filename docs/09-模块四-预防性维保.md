# 步骤 09 — 模块四 预防性维保

对应论文第3章 3.1 节模块四，含 3 个子功能。管理端侧边栏一级菜单为「预防性维保」。

## 一、功能

### 维保计划管理
- 物业制定周期性维保任务，维保类型含半月保、季度检、半年保、年检
- 按电梯类型自定义计划模板，模板包含维保类型、周期天数、检查项清单
- 计划关联具体电梯，支持批量选择电梯生成计划
- 设置计划生效日期、失效日期、周期天数、负责人
- 系统按周期自动推算下次维保日期，半月保为 15 天，季度检为 90 天
- 计划启用与停用，停用后不再生成巡检工单
- 计划修改后重新推算后续维保日期
- 计划列表按小区、电梯、维保类型、计划状态筛选
- 展示计划的执行情况：应执行次数、已执行次数、完成率
- 对即将到期的计划提前标记提示

### 定期巡检执行
- 系统按维保计划的周期自动生成巡检工单并派发给负责人，通过定时任务每日 01:00 扫描到期计划
- 定时任务已注册到 `sys_job`，调用目标 `inspectionGenerateTask.execute()`，同时标记超期任务
- 同一计划同一周期只生成一次巡检工单，避免重复派发
- 生成的巡检工单推送给负责维修员，同时在管理端巡检任务列表可见
- 维修员在小程序端查看本人的巡检任务列表，展示电梯位置、维保类型、计划维保日期
- 进入巡检执行页，按电梯对应的模板加载检查项清单
- 检查项覆盖曳引机、钢丝绳、门系统、安全装置、控制系统、轿厢照明、报警装置等
- 现场打卡，记录打卡时间与打卡位置
- 逐项勾选检查结果：正常、异常、不适用
- 对异常项填写异常说明，并可上传现场照片
- 全部检查项完成后提交，系统归档形成巡检记录与维保档案
- 提交后巡检工单状态变为已完成，关联的维保计划下次维保日期自动向后推算
- 未在计划日期完成的巡检任务标记为超期，进入预警监控
- 巡检任务按执行状态筛选
- 巡检记录导出

### 维保档案归档
- 系统自动汇总每次巡检与维修的详情，形成电梯全生命周期历史维保记录
- 归档类型含巡检记录与维修记录两类
- 归档内容包含：电梯信息、维保类型、计划维保日期、实际执行日期、执行人、检查项结果明细、异常项与处理情况
- 按电梯维度展示完整维保履历，时间倒序排列
- 支持按电梯、时间范围、维保类型、执行人检索归档记录
- 支持查看单次巡检的完整明细
- 统计每台电梯的维保完成率、巡检合格率，作为健康评分的输入
- 维保档案导出为 Excel，供物业存档与监管备查
