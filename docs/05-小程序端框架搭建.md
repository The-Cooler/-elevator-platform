# 步骤 05 — 小程序端工程搭建

面向业主、物业、维修员三类角色的 uni-app 小程序。管理员使用 `admin-web`，不使用小程序。

## 一、功能

### 工程基础搭建
- 建立 `uniapp-app` 工程，技术栈为 uni-app 3 + Vue 3 + Pinia
- 配置 `pages.json` 的页面路由与 tabBar，底部为首页、消息、我的三项
- 配置 `manifest.json`，目标平台含微信小程序与 H5
- 配置 `vite.config.js` 开发代理，`/dev-api` 转发到后端 8080
- 建立 `src/utils/request.js` 请求封装：注入 `Authorization` 令牌、统一解包 `{code,msg,data}`、401 清空登录态并跳转登录页
- 建立 `src/utils/dict.js` 字典映射：工单状态、故障类型、维保类型、巡检状态的文案与配色
- 建立 `src/store/user.js` 登录态管理，token 与用户信息持久化到本地存储
