# 步骤 06 — 模块一 基础数据与权限管理

对应论文第3章 3.1 节模块一，含 3 个子功能。管理端侧边栏一级菜单为「基础数据与权限管理」。

## 一、功能

### 用户注册与登录
- 业主、物业、维修员、管理员四类角色注册：填写用户名、密码、真实姓名、手机号、所属小区，选择角色，与论文 3.1 节「支持四类角色注册」一致
- 账号密码登录，集成图形验证码校验
- 手机号密码登录，对应论文「通过手机号或账号密码登录」中的手机号登录方式
- 手机号在 `sys_user.phonenumber` 上有唯一索引，注册时校验手机号不重复
- 登录成功签发 JWT 令牌，令牌有效期可配置
- 退出登录，令牌失效
- 密码使用加密存储，不明文落库
- 管理员在管理端维护四类角色账号：查询、新增、修改、重置密码、启用停用
- 业主数据范围隔离：业主只能看到本人的报修工单与个人信息

### 角色权限管理
- 四类角色定义：业主、物业、维修员、管理员
- 业主权限：报修提交、证据上传、进度查询、结果确认
- 物业权限：报修审核、工单派发、维保计划管理、工单异常处理、统计报表查看
- 维修员权限：接单、维修过程填报、巡检执行
- 管理员权限：小区与电梯基础信息维护、角色权限配置、用户账号管理
- 管理端角色列表查询、新增、修改、删除
- 角色分配菜单与按钮权限，权限树按五个模块分组展示
- 角色启用停用
- 用户与角色的分配与调整
- 数据权限按所属小区隔离：物业与维修员只能查看本人所属小区的工单，管理员不受限制

### 基础信息管理
- 小区信息维护：小区名称、地址、建成时间、物业联系人、联系电话
- 楼栋信息维护：楼栋号、单元号、关联小区，支持按小区筛选
- 电梯信息维护：电梯编号、品牌、型号、所在楼栋、单元号、维保单位、投用日期、使用年限、电梯状态
- 电梯年检报告等证件附件上传与在线预览
- 电梯台账按小区、楼栋、状态多条件查询与导出
- 电梯状态字典维护：正常运行、停梯检修、已报废
- 小区、楼栋、电梯三级级联选择组件，供报修与维保模块复用
