# 步骤 07 — 模块二 故障报修与跟踪

对应论文第3章 3.1 节模块二，含 4 个子功能。管理端侧边栏一级菜单为「故障报修与跟踪」。

## 一、功能

### 故障一键报修
- 业主在用户端选择故障电梯，通过小区、楼栋、电梯三级级联选择
- 电梯选择支持按电梯编号搜索，展示电梯编号、品牌、所在楼栋与当前状态
- 填写故障现象，提供异响、停梯、困人、门关不上、按钮失灵等预设选项，可补充文字描述
- 初选故障等级，紧急或一般
- 提交后生成报修工单，记录报修人与报修时间，初始状态为待处理
- 同一电梯在同一时间已有未结工单时给出提示，避免重复报修
- 提交成功后展示工单编号与预计响应说明
- 管理端查看报修工单列表，支持查看详情与驳回重审
- 报修工单导出

### 故障分级管理
- 系统预设故障等级：紧急、一般
- 紧急等级适用于困人、停梯、溜梯等危及人身安全的情形
- 一般等级适用于异响、按键失灵、照明故障等不影响安全的情形
- 业主报修时初选等级，系统按故障现象给出默认等级建议
- 物业审核时可手动调整优先级，调整为紧急时高亮提示
- 故障等级字典维护：等级名称、等级值、颜色标识、排序号
- 等级变更记录到工单状态流转表，留痕可查
- 故障等级属于字典数据，维护复用若依框架原生的字典接口，不另建平行接口

### 多媒体证据上传
- 业主在报修时上传现场照片或短视频作为故障凭证
- 支持常见图片格式：jpg、jpeg、png、webp
- 支持常见视频格式：mp4、mov
- 限制单张图片不超过 10MB，单个视频不超过 50MB，超出时给出明确提示
- 上传过程显示进度条，支持取消上传
- 支持多张图片与多段视频，最多各 5 个
- 上传成功后展示缩略图，可删除重新上传
- 不上传证据也可提交报修，但给出建议上传的提示
- 管理端查看全量证据附件库，按工单、上传时间、文件类型筛选
- 管理端图片在线预览、视频在线播放
- 证据附件与工单关联存储，工单详情页可直接查看

### 报修进度跟踪
- 业主在用户端查看本人全部报修记录列表，展示工单编号、电梯、故障现象、当前状态、报修时间
- 按状态筛选：全部、待处理、已派单、维修中、已完成
- 报修详情页以时间轴展示全流程：报修提交、物业审核、派单、接单、到场、维修中、已修复、业主确认
- 时间轴每个节点展示发生时间与操作人
- 展示维修员的处理说明与更换配件信息
- 展示预计到场时间与当前进度说明
- 工单完成后业主确认故障消除，工单闭环
- 业主对维修结果不满意时可提交申诉，工单转物业处理
- 管理端报修进度跟踪页展示全部工单的全流程时间轴与各状态停留时长
- 管理端可按小区、楼栋、电梯、状态、时间段组合查询
