# 步骤 01 — 工程搭建

## 一、功能

### 后端工程搭建
- 克隆 RuoYi-Vue 官方仓库到 `backend/`，检出 `springboot3` 分支
- 改造 Maven 坐标：`groupId` 为 `com.ruoyi`，`artifactId` 为 `elevator`，`name` 为「老旧小区电梯故障报修与维保跟踪平台」
- 新建 `ruoyi-elevator` 子模块并接入父 pom 的 `modules` 列表
- 配置 `ruoyi-admin/src/main/resources/application.yml` 中的 MySQL 连接、Redis 连接
- 配置 `ruoyi-admin/src/main/resources/application-druid.yml` 数据源
- 启动 `RuoYiApplication`，确认端口正常监听、控制台无报错

**交付物**

| 类型 | 清单 |
| --- | --- |
| 工程项目 | backend/ 完整 RuoYi-Vue 工程 |
| Maven 模块 | backend/ruoyi-elevator/pom.xml |
| 配置文件 | backend/ruoyi-admin/src/main/resources/application.yml、application-druid.yml |
| 启动类 | backend/ruoyi-admin/src/main/java/com/ruoyi/RuoYiApplication.java |
| 构建文件 | backend/pom.xml |

### 管理端工程搭建
- 克隆 RuoYi-Vue3 官方仓库到 `admin-web/`
- 修改 `package.json` 的 `name`、`description` 为本项目
- 修改 `.env.development` 与 `.env.production` 的 `VITE_APP_TITLE` 为「电梯故障报修与维保跟踪平台」
- 配置 `vite.config.js` 的开发代理指向后端端口
- 执行依赖安装，启动开发服务器，确认登录页可访问

**交付物**

| 类型 | 清单 |
| --- | --- |
| 工程项目 | admin-web/ 完整 RuoYi-Vue3 工程 |
| 配置文件 | admin-web/package.json、.env.development、.env.production、vite.config.js |

### 小程序端工程搭建
- 建立 uni-app 工程到 `uniapp-app/`
- 配置 `package.json` 的 `name` 为本项目小程序端名称
- 配置 `manifest.json`，目标平台含微信小程序与 H5
- 配置 `pages.json` 的页面路由与 tabBar
- 配置 `.env` 与 `vite.config.js` 的开发代理指向后端端口
- 执行依赖安装，确认可构建

**交付物**

| 类型 | 清单 |
| --- | --- |
| 工程项目 | uniapp-app/ 完整 uni-app 工程 |
| 配置文件 | uniapp-app/package.json、vite.config.js |
| 配置 | uniapp-app/src/manifest.json、pages.json |

### 工程联通验证

- 小程序端通过代理调通后端登录接口，图形验证码正常获取
